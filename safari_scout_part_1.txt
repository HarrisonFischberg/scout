2. Architecture (the full picture, for context)

Rule for every part: all permission checks run on the device. The client never relies on the server to enforce safety.

3. Toolbar button and panel
	•	Clicking the binoculars toggles the Scout panel for the current window.
	•	The panel remembers for each tab whether it was open and which conversation it showed, and restores both when you switch back to that tab.
	•	The keyboard shortcut does the same as clicking the button.
	•	The panel is disabled in private browsing, with a short explanation.
	•	A setting hides the toolbar button completely.
	•	Build the panel shell: a header with the name and icon, an empty conversation area, an input box (it can be inactive until Part 2), and a settings entry point.

4. Message bridge (panel ↔ background worker)
	•	Long-lived port for streaming events (progress, task state). It reconnects automatically with exponential backoff.
	•	Request/response messages for one-off calls. Every message is { type, request_id, payload }.
	•	Sender validation: accept only messages from Scout's own panel and content scripts. Reject anything from a web page origin.
	•	Schema validation: validate every message before handling it. Return schema-error for anything malformed.
	•	Standard error types: timeout, blocked-by-user, schema-error, unhandled.
	•	Put the message types and schemas in one shared module so Parts 2 and 3 can add to it.

Platform note
Check whether the target browser supports a native side panel or sidebar. If it doesn't, use a toolbar popover or a panel inside the page, and note which one you chose.

Part 1 acceptance criteria
	•	The rename check returns nothing, and the binoculars icon appears at every size.
	•	The binoculars button and the shortcut both toggle the panel.
	•	Panel open/closed state and conversation are remembered per tab.
	•	The panel doesn't work in private browsing.
	•	Messages from web page origins are rejected, and malformed messages return schema-error.
	•	The port reconnects after the background worker restarts.
