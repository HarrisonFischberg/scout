Scout for Safari

Add your API key to start

Scout for Safari uses your own Anthropic or OpenAI key, kept in your Keychain. Page text you ask about is sent to that provider. Your provider bills your account for every request Scout for Safari makes, at the provider's prices. Scout for Safari shows an estimated cost after each answer or task.

Off in Private Browsing

Scout for Safari does not run in private windows, so nothing you browse privately is sent to an AI provider or saved. Open the page in a regular window to use it.

        Toolbar button

        Shortcut: Control-Shift-S on Mac opens and closes Scout for Safari. Safari does not let extensions hide their own button or change the shortcut. To hide the button on Mac, choose View > Customize Toolbar in Safari and drag the binoculars out. On iPhone and iPad, Scout for Safari lives in the page menu (the button in the address bar).

        Diagnostics (debug build)

        Records what the last 5 runs did, on this device only, so you can paste it into a bug report. Never includes page text, API keys, or form values.
