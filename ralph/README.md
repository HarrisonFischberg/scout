# Ralph loop

Fresh-context shell loop: https://github.com/coleam00/ralph-loop-quickstart.
Review its scripts and permission config before running; never blindly
overwrite project config. Holds `ralph.sh`, loop logs, browser-verification
artifacts.

Limits per approved run: 10 iterations, 5 `/goal` turns per iteration. Stop
after two consecutive iterations without meaningful progress. Reaching the
iteration limit is not completion.
