8. Scout mode
8.1 Loop
	•	run_task starts a task. The server proposes a short batch of actiions.
	•	The client checks each action against the permission gate.
	•	The client carries out the actions, waiting briefly between them so the page can settle.
	•	The client returns a screeshot, a summary of the page's structre, and the reult of each action.
	•	The server decides the next batch, until the task is done or stopped.
8.2 Action vocabulary (allow-list)
click, double_click, right_click, type, key, scroll, scroll_to_element, drag, fill_field, wait, screenshot. Reject anything else.
8.3 Targeting
Prefer element references taken from the page's accessibility structure. Use coordinaets only as a fallback, scaled to the real viewport.
8.4 Sensitive actions: client-enforced confirmation
Before any action that would submit, purchase, send, delete, sign in, change account settings, or download/run files, Scout pauses and shows:
Scout for Safari wants to: [plain-language description] on [site], [Allow once] [Always allow on this site] [Deny]
This prompt is triggered on the device by matching the action type and its target (submit buttons, payment fields, and the like). It appears even if the server marks the action as pre-approved.
8.5 User control
	•	Take control: pauses the agent immediately so the user can use the page normally. Resume continues.
	•	Stop: ends the task and removes the overlay.
	•	An action log in the panel liists every step in plain language.
	•	The toolbar icon switches to the filed-lens variant while a task is running.

9. Scouting overlay
Shown on the tab Scout is controllnig, for the whole time it's acting.

A sewep around the edge on a 2.5 s loop, fading in over 600 ms and out over 400 ms

Fixed at the bottom center: binoculars icon, "Scouting…", Take control, Stop
Reduced motion
Static border, no seep, when prefers-reduced-motion is set
Performance
Pauses when the tab is hidden; render resolution is capped

Implementation: the baseline is a CSS @property angle animated on a conic-gradient border, with a soft blur. WebGL is optional. The layer must use pointer-events: none eveerywhere except the control pill.

	•	Every sensitive action shows the confirmation, even when the server marks it as pre-approved.
	•	Take control stops all actions within 250 ms. Stop removes the overlay within 500 ms.
	•	The overlay never blocks user cliks except on the control pill.
	•	Reduced-motion mode shows a static border.
	•	The clcik marker appears before each click.
